# Sysdesk Help Desk Ticketing System

Hands-on IT Support portfolio project demonstrating the setup, configuration, and day-to-day operation of a professional ticketing system.

## Purpose

Ticketing systems are the backbone of Help Desk and Service Desk operations. They convert unstructured user requests into structured, trackable work — ensuring accountability, consistent workflows, measurable performance against SLAs, clear communication, and continuous improvement through data and knowledge capture.

This project shows how I configured and used **Sysdesk** to deliver organized, professional IT support.

## What I Built & Did

- Configured Sysdesk with realistic categories, priority levels, assignment rules, and SLA policies to mirror enterprise Help Desk environments
- Created and managed end-to-end ticket workflows (logging → triage → investigation → resolution → closure)
- Resolved a series of realistic IT support tickets covering common issues such as account problems, software issues, connectivity, and hardware
- Wrote professional ticket notes including problem description, troubleshooting steps taken, root-cause analysis, resolution, and verification
- Used internal notes and status updates to practice multi-technician collaboration and clear audit trails
- Generated knowledge-base style documentation from closed tickets to support future self-service and reduce repeat incidents

## Skills Demonstrated

- Ticket lifecycle management
- Structured troubleshooting methodology
- Technical documentation & professional communication
- SLA awareness and prioritization
- Root-cause analysis
- Help Desk / Service Desk workflow best practices
- Evidence-based resolution (screenshots & verification steps)
